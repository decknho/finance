# 📊 Finance — Educação Financeira Sustentável

O **Finance** é um projeto desenvolvido como parte da disciplina **Atividade Extensionista**, do curso de Ciência da Computação da Uninter. A aplicação tem como objetivo auxiliar na organização das finanças pessoais e promover o acesso à educação financeira, incluindo conceitos relacionados a investimentos sustentáveis.

🌐 **Acesse o projeto:** [Finance — Acessar aplicação](COLE_AQUI_O_LINK_DO_GITHUB_PAGES)

## 🎯 Objetivo

Aplicar os conhecimentos adquiridos durante a graduação no desenvolvimento de uma solução tecnológica que contribua para a educação financeira, incentivando o planejamento consciente, a organização do dinheiro e o conhecimento sobre investimentos.

## ✨ Funcionalidades

- **Dashboard financeiro:** visualização de receitas, despesas, saldo e informações financeiras por meio de gráficos.
- **Controle financeiro:** registro e acompanhamento das movimentações financeiras.
- **Simulador de investimentos:** exploração de cenários para compreender melhor alternativas de investimento.
- **Educação financeira:** conteúdos explicativos sobre receitas, despesas, saldo, patrimônio e outros conceitos fundamentais.
- **Visualização de dados:** apresentação de informações financeiras de forma organizada e intuitiva.

## 🌱 Impacto social e sustentabilidade

O Finance busca tornar conceitos financeiros mais acessíveis, contribuindo para que as pessoas compreendam melhor sua situação financeira e desenvolvam hábitos de planejamento consciente.

O projeto também aborda a temática dos investimentos sustentáveis, aproximando a educação financeira de questões relacionadas à responsabilidade ambiental e ao planejamento de longo prazo.

## 🚀 Acesso e execução

### Acessar online

O projeto será disponibilizado gratuitamente pelo **GitHub Pages**, permitindo o acesso à aplicação diretamente pelo navegador.

**Link:** [Finance](https://deckn.github.io/finance/)

### Executar localmente

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador ou utilize uma extensão como Live Server no Visual Studio Code.
